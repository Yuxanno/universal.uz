# Функция добавления кода-префикса к цене на ценнике

## Описание
Добавлена возможность вводить числовой код-префикс при печати ценников. Код отображается перед ценой на ценнике.

## Как работает

### Пример использования:
- **Товар**: Молоко
- **Цена**: 100 000 сум
- **Введенный код**: 1
- **Результат на ценнике**: `1 100 000 so'm`

### Без кода:
- **Результат на ценнике**: `100 000 so'm`

## Где доступно
Функция добавлена во всех местах печати ценников:
1. **Админ панель** → Махсулотлар (Products)
2. **Касса** → Махсулотлар (Products)
3. **Админ панель** → Омборлар (Warehouses)

## Интерфейс

### Поле ввода кода
- **Название**: "Kod prefiksi (ixtiyoriy)"
- **Тип**: Числовое поле (только цифры)
- **Placeholder**: "Masalan: 1, 2, 3..."
- **Обязательность**: Необязательное поле

### Предпросмотр
Под полем ввода отображается предпросмотр того, как будет выглядеть цена на ценнике:
- С кодом: `Ценникда: 1 100 000 so'm`
- Без кода: `Ценникда: 100 000 so'm`

## Технические детали

### Состояние
```typescript
const [printCodePrefix, setPrintCodePrefix] = useState('');
```

### Формирование цены для печати
```typescript
const displayPrice = printCodePrefix.trim() 
  ? `${printCodePrefix.trim()} ${price.toLocaleString()}` 
  : price.toLocaleString();
```

### HTML на ценнике
```html
<div class="price">${displayPrice} so'm</div>
```

## Особенности
1. ✅ Поле принимает только цифры (type="number")
2. ✅ Код необязателен - можно печатать без него
3. ✅ Код отображается только если цена включена (checkbox "Narxni ko'rsatish")
4. ✅ Пробел автоматически добавляется между кодом и ценой
5. ✅ Предпросмотр обновляется в реальном времени
