# 🏷️ Финальный макет ценников

## ✅ Готово!

### Макет ценника (58mm x 40mm):

```
┌─────────────────────────────────────┐
│                                     │
│          100 000 so'm               │ ← Цена 20pt (центр)
│                                     │
│                  ┌──────────┐      │
│  BRUK            │          │      │ ← Название 13pt
│  Kod: 2602       │  QR-код  │      │ ← Код 11pt
│                  │  24mm    │      │
│                  └──────────┘      │
│                                     │
└─────────────────────────────────────┘
```

## 📐 Размеры:

| Элемент | Размер | Описание |
|---------|--------|----------|
| **Ценник** | 58mm x 40mm | Стандартный размер |
| **Цена** | 20pt bold | **По центру**, крупнее текста |
| **QR-код** | 24mm x 24mm | Оптимальный для сканирования |
| **Название** | 13pt bold | Слева |
| **Код** | 11pt semibold | Слева под названием |

## 🎯 Ключевые особенности:

1. **Цена по центру** - легко видна
2. **Цена крупная** (20pt) - больше чем название (13pt)
3. **QR-код справа** - удобно сканировать
4. **Компактный дизайн** - все помещается в 58x40мм

## 📱 Где работает:

- ✅ Админ панель: `/admin/products`
- ✅ Касса: `/cashier/products`
- ✅ Склады: `/admin/warehouses`
