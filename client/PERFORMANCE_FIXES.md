# Решения проблем производительности

## Критические исправления:

### 1. Виртуализация списков
```bash
npm install react-window
```

Используйте `react-window` для рендера только видимых элементов корзины.

### 2. Оптимизация поиска
- Добавьте индексацию продуктов по коду
- Ограничьте результаты поиска (макс 50 товаров)
- Используйте Web Workers для поиска

### 3. Уменьшите debounce время
Измените с 100ms на 300ms для меньшего количества запросов:
```typescript
const debouncedSearchQuery = useDebounce(searchQuery, 300);
```

### 4. Отключите тяжелые эффекты
- Уберите backdrop-blur (очень тяжелый)
- Упростите градиенты
- Уберите анимации scale на hover

### 5. Пагинация продуктов
Загружайте продукты порциями по 100 штук, а не все сразу.

### 6. Мемоизация компонентов
Оберните CartItemRow в React.memo:
```typescript
export default React.memo(CartItemRow);
```

### 7. Оптимизация кэша
Увеличьте время кэша продуктов с 5 до 30 минут.

## Временное решение (БЫСТРО):

1. Ограничьте результаты поиска:
```typescript
const results = products
  .filter(p => /* условие */)
  .slice(0, 50); // Только первые 50
```

2. Отключите backdrop-blur в CSS (самый тяжелый эффект)

3. Увеличьте debounce до 300-500ms
