# 🔢 Автоматический выбор свободного кода

## ✅ Что исправлено:

### Проблема:
При вводе существующего кода товара система показывала предупреждение:
```
⚠️ Kod "123" band. Saqlashda avtomatik bo'sh kod tanlanadi.
```

Но код **не менялся автоматически** - нужно было вручную изменить.

### Решение:
Теперь при вводе занятого кода система **автоматически** выбирает следующий свободный код!

## 🎯 Как работает:

### 1. Пользователь вводит код
```
Код: 123 [Enter]
```

### 2. Система проверяет код
```javascript
const res = await api.get(`/products/check-code/123`);
if (res.data.exists) {
  // Код занят!
}
```

### 3. Автоматически получает свободный код
```javascript
const nextCodeRes = await api.get('/products/next-code');
setFormData(prev => ({ ...prev, code: nextCodeRes.data.code }));
```

### 4. Код автоматически заменен (тихо)
```
Код: 124 ✅
```
**Без модального окна!** Только в консоли (F12):
```
Kod "123" band edi. Avtomatik yangi kod tanlandi: 124
```

## 📋 Алгоритм:

```javascript
const checkCodeExists = async (code: string) => {
  if (!code) return;
  
  if (editingProduct) {
    // При редактировании - только предупреждение
    if (codeExists) {
      setCodeError(`Kod "${code}" allaqachon mavjud`);
    }
  } else {
    // При добавлении - автоматическая замена
    if (codeExists) {
      // 1. Получить следующий свободный код
      const nextCode = await getNextCode();
      
      // 2. Автоматически заменить
      setFormData({ ...formData, code: nextCode });
      
      // 3. Тихо (без модального окна)
      console.log(`Kod "${code}" band edi. Avtomatik yangi kod tanlandi: ${nextCode}`);
      
      // 4. Очистить ошибку
      setCodeError('');
    }
  }
};
```

## 🔍 Серверная часть:

### Endpoint: `/products/next-code`

```javascript
router.get('/next-code', auth, async (req, res) => {
  // 1. Определить базовый код (зависит от склада)
  let baseCode = 1;
  if (warehouseId) {
    // Для разных складов разные диапазоны
    baseCode = warehouseIndex * 100000;
  }
  
  // 2. Получить все занятые коды
  const usedCodes = new Set(
    allProducts.map(p => parseInt(p.code))
  );
  
  // 3. Найти первый свободный код
  let nextCode = baseCode;
  while (usedCodes.has(nextCode)) {
    nextCode++;
  }
  
  // 4. Вернуть свободный код
  res.json({ code: String(nextCode) });
});
```
