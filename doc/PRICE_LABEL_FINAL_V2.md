## 🎯 Ключевые улучшения:

### 1. Цена по центру всего ценника
- ✅ Отдельная строка сверху
- ✅ `text-align: center` на всю ширину (58mm)
- ✅ Крупный шрифт 22pt
- ✅ Занимает верхнюю часть

### 2. Имя и код не выходят за QR
- ✅ Ограничены шириной: `max-width: 28mm`
- ✅ `word-wrap: break-word` - перенос длинных слов
- ✅ Всегда в пределах QR-кода

### 3. Когда цена есть - контент ниже
- ✅ Цена в отдельной строке с `margin-bottom: 2mm`
- ✅ QR и текст автоматически опускаются
- ✅ Вертикальное центрирование через `justify-content: center`

### 4. Крупнее шрифты
- ✅ Имя: 15pt (было 13pt)
- ✅ Код: 13pt (было 11pt)
- ✅ Цена: 22pt (самая крупная)

## 🔍 Детали реализации:

### 1. Цена по центру
```css
.price-row {
  width: 100%;        /* Занимает всю ширину 58mm */
  text-align: center; /* Текст по центру */
}
```

### 2. Ограничение ширины текста
```css
.left-section { 
  flex: 0 0 28mm;    /* Ровно 28mm */
  max-width: 28mm;   /* Не больше */
}
```
**28mm** = ширина текста (чуть больше QR 24mm для баланса)

### 3. Перенос длинных слов
```css
.name {
  word-wrap: break-word;      /* Стандартный перенос */
  overflow-wrap: break-word;  /* Современный перенос */
}
```

### 4. Вертикальное центрирование
```css
.label {
  display: flex;
  flex-direction: column;
  justify-content: center;  /* Центр по вертикали */
}
```
