# 🏷️ Обновление макета ценников

## Что изменено:

### Старый макет:
```
┌─────────────────────────────────┐
│  100 000 so'm    ┌──────────┐  │
│  BRUK            │          │  │
│  Kod: 2602       │  QR-код  │  │
│                  │          │  │
│                  └──────────┘  │
└─────────────────────────────────┘
```

**Проблемы:**
- Цена занимала 2 строки (число + "so'm")
- QR-код был слишком большой (26mm)
- Неэффективное использование пространства

### Новый макет:
```
┌─────────────────────────────────┐
│                  100 000 so'm   │
│  BRUK            ┌──────────┐  │
│  Kod: 2602       │          │  │
│                  │  QR-код  │  │
│                  └──────────┘  │
└─────────────────────────────────┘
```

**Улучшения:**
- ✅ Цена в одну строку над QR-кодом
- ✅ QR-код оптимального размера (24mm)
- ✅ Лучшее использование пространства
- ✅ Все помещается в 58x40мм

## Особенности:

### Цена (опционально):
- Отображается только если включена галочка "Narxni ko'rsatish"
- Сохраняется в localStorage
- Расположена над QR-кодом в одну строку
- Формат: `100 000 so'm` (с пробелами для читаемости)

### QR-код:
- Размер: 24mm x 24mm (оптимально для сканирования)
- Содержит: `{ id, code, name }`
- Генерируется через API: `https://api.qrserver.com/v1/create-qr-code/`

### Название товара:
- Слева, вверху
- Жирный шрифт 13pt
- Автоматическая конвертация в кириллицу (uz функция)

### Код товара:
- Слева, внизу
- Формат: `Kod: 2602`
- Шрифт 11pt semibold

## Тестирование:

### Как проверить:
1. Откройте страницу "Махсулотлар" (Products)
2. Нажмите на кнопку "Принтер" у любого товара
3. Установите количество ценников
4. Включите/выключите "Narxni ko'rsatish"
5. Нажмите "Чоп этиш"

### Ожидаемый результат:
- Ценник открывается в новом окне
- Размер: 58mm x 40mm
- Цена (если включена) над QR-кодом в одну строку
- QR-код 24mm x 24mm
- Название и код слева
- Все элементы помещаются без обрезки
