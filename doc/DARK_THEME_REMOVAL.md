# Удаление темной темы

## Выполненные изменения

### 1. Удален ThemeContext
- Удален файл `client/src/context/ThemeContext.tsx`
- Удалены все импорты и использование `ThemeProvider`, `useTheme`
- Обновлен `client/src/App.tsx` - убран `ThemeProvider` из дерева компонентов

### 2. Очищены все компоненты
Удалены все `dark:` классы из следующих файлов (30 файлов):
- Все компоненты в `client/src/components/`
- Все страницы в `client/src/pages/`
- Все лейауты в `client/src/layouts/`

### 3. Очищены CSS файлы
- `client/src/index.css` - полностью переписан без dark-режимов
- `client/src/design-system.css` - удалены все dark-режимы
- `client/src/styles/design-system.css` - удалены `.dark` классы и переменные
- `client/src/styles/modal-fix.css` - удалены все dark-режимы и исправлены синтаксические ошибки
- `client/src/pages/admin/Kassa.modern.css` - удалены dark-режимы

### 4. Заменены кастомные цветовые классы
- Заменены `surface-*` на `neutral-*` (13 файлов)
- Заменены `brand-*` на `red-*` (30 файлов)
- Заменены `danger-*` на `red-*`
- Заменены `warning-*` на `red-*`
- Заменены `primary-*` на `red-*`

### 5. Исправлены ошибки
- Удалены все пустые `@apply;` директивы
- Удалены сломанные `@apply:class:class;` директивы
- Исправлены лишние закрывающие скобки в CSS
- Файл `index.css` полностью переписан с чистым синтаксисом
- Удалены сломанные классы типа `:bg-neutral-900` (74 файла)
- Исправлены цвета текста в модальных окнах (белый на градиентах, черный на белом фоне)

### 6. Результат
- Приложение теперь работает только в светлой теме
- Все навбары, хедеры и компоненты имеют белый фон
- Удалены все упоминания темной темы из кодовой базы
- Код стал чище и проще в поддержке
- CSS файлы валидны и без ошибок
- Модальные окна имеют правильные цвета текста:
  - Белый текст на красных градиентных заголовках
  - Черный текст на белом фоне
  - Правильные цвета для поисковых полей

## Проверка
Все файлы проверены на наличие ошибок TypeScript - ошибок не обнаружено.
CSS файлы исправлены и готовы к использованию.
