# 🏷️ Настройка ценников

## Что добавлено?

Теперь можно **настраивать отображение цены** на ценниках!

### ✨ Новые возможности:

1. **Чекбокс "Narxni ko'rsatish"**
   - Включить/выключить отображение цены
   - Настройка сохраняется автоматически

2. **Увеличенный QR-код**
   - Размер: 26mm x 26mm (было 22mm)
   - Лучше сканируется

3. **Улучшенный дизайн**
   - Цена крупным шрифтом (18pt)
   - Цена над названием товара
   - Лучшая читаемость

## 🎯 Как использовать?

### 1. Откройте печать ценника

В админ панели или у кассира:
- Нажмите на иконку принтера 🖨️
- Откроется модальное окно

### 2. Настройте отображение

В модальном окне:
- ✅ **Галочка включена** → цена будет на ценнике
- ❌ **Галочка выключена** → цена скрыта

### 3. Настройка сохраняется

- Выбор сохраняется в localStorage
- При следующей печати галочка останется в том же состоянии
- Работает для всех пользователей на этом устройстве

### Без цены (галочка выключена):

```
┌─────────────────────────────────────┐

│  JENSKI MYUMYU  ← Название (13pt)  │  [QR-код]
│  Kod: 1029      ← Код (11pt)       │  [24mm]
│                                     │
└─────────────────────────────────────┘
```

**Изменения в макете:**
- ✅ Цена теперь **по центру над QR-кодом**
- ✅ Цена **крупнее** (20pt) чем название (13pt)
- ✅ QR-код оптимального размера (24mm)
- ✅ Лучшее использование пространства 58x40мм

## 🎨 Технические детали

### Размеры:

| Элемент | Размер | Вес |
|---------|--------|-----|
| Цена | 20pt | Bold |
| Название | 13pt | Bold |
| Код | 11pt | Semibold |
| QR-код | 24mm x 24mm | - |
| Ценник | 58mm x 40mm | - |

### Цвета:

- Цена: `#000` (черный)
- Название: `#000` (черный)
- Код: `#333` (темно-серый)

### Отступы:

- Между ценой и QR-кодом: 1mm
- Между названием и кодом: 1.5mm
- Между текстом и QR: 2mm
- Padding ценника: 2mm

## 💾 Сохранение настроек

### localStorage:

```javascript
// Ключ
'showPriceOnLabel'

// Значение
true  // Показывать цену
false // Скрыть цену
```

### Проверить настройку:

```javascript
// В консоли браузера (F12):
console.log(localStorage.getItem('showPriceOnLabel'));
// Вернет: "true" или "false"
```

### Сбросить настройку:

```javascript
// В консоли браузера:
localStorage.removeItem('showPriceOnLabel');
location.reload();
// Вернется к значению по умолчанию (true)
```

## 🔧 Настройка по умолчанию

По умолчанию цена **показывается** (галочка включена).

Чтобы изменить:

```typescript
// В Products.tsx (admin или cashier)
const [showPriceOnLabel, setShowPriceOnLabel] = useState(() => {
  const saved = localStorage.getItem('showPriceOnLabel');
  return saved ? JSON.parse(saved) : false; // false = скрыть по умолчанию
});
```

## 🐛 Troubleshooting

### Галочка не сохраняется?

```javascript
// Проверьте localStorage:
console.log(localStorage.getItem('showPriceOnLabel'));

// Если null, попробуйте вручную:
localStorage.setItem('showPriceOnLabel', 'true');
location.reload();
```

### Цена не отображается?

1. Проверьте галочку в модальном окне
2. Проверьте localStorage
3. Перезагрузите страницу

### QR-код не сканируется?

- Увеличен до 26mm x 26mm
- Используется уровень коррекции "H"
- Должен сканироваться лучше
