## Настройки производительности

В `performance.config.ts`:

```typescript
export const PERFORMANCE_CONFIG = {
  INITIAL_LOAD: 100,        // Первая загрузка
  ITEMS_PER_PAGE: 50,       // Размер страницы
  MAX_SEARCH_RESULTS: 50,   // Макс результатов поиска
  SEARCH_DEBOUNCE: 300,     // Задержка поиска
  PRODUCTS_CACHE_TIME: 5 * 60 * 1000, // Кэш 5 мин
};
```

## Мониторинг

Проверьте производительность в Chrome DevTools:
1. Performance tab
2. Lighthouse audit
3. Memory profiler

Целевые метрики:
- First Contentful Paint < 1s
- Time to Interactive < 2s
- Total Blocking Time < 200ms
