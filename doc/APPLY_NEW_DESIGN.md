# 🎨 Применить новый дизайн - Простая инструкция

## ✅ Шаг 1: Дизайн-система уже подключена!

Файл `client/src/main.tsx` уже обновлен. ✅

---

## ✅ Шаг 2: Переименуйте файлы вручную

### Login страница:

1. Откройте папку `client/src/pages/`
2. Найдите файл `Login.professional.tsx`
3. Переименуйте его в `Login.tsx` (замените существующий или переименуйте старый в `Login.old2.tsx`)

### Dashboard страница:

1. Откройте папку `client/src/pages/admin/`
2. Найдите файл `Dashboard.professional.tsx`
3. Переименуйте его в `Dashboard.tsx` (замените существующий или переименуйте старый в `Dashboard.old2.tsx`)

---

## ✅ Шаг 3: Запустите проект

Откройте терминал (PowerShell или CMD) и выполните:

```cmd
cd client
npm run dev
```

---

## ✅ Шаг 4: Откройте браузер

Откройте http://localhost:5173

Нажмите `Ctrl + Shift + R` для жесткой перезагрузки

## 🐛 Если не работает

### Очистите кэш:

```cmd
cd client
rmdir /s /q node_modules\.vite
npm run dev
```

### Жесткая перезагрузка:

В браузере нажмите `Ctrl + Shift + R`
