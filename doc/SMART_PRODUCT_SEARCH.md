## 📋 Алгоритм поиска:

```typescript
function searchProducts(products, query) {
  return products.filter(product => {
    // 1. Поиск по коду
    if (product.code.includes(query)) {
      return true;
    }
    
    // 2. Поиск по названию (прямое совпадение)
    if (product.name.toLowerCase().includes(query.toLowerCase())) {
      return true;
    }
    
    // 3. Конвертируем запрос в кириллицу и ищем
    const cyrillicQuery = uzLatToCyr(query);
    if (product.name.toLowerCase().includes(cyrillicQuery.toLowerCase())) {
      return true;
    }
    
    // 4. Конвертируем название товара в кириллицу и ищем
    const cyrillicName = uzLatToCyr(product.name);
    if (cyrillicName.toLowerCase().includes(query.toLowerCase())) {
      return true;
    }
    
    // 5. Оба в кириллице
    if (cyrillicName.toLowerCase().includes(cyrillicQuery.toLowerCase())) {
      return true;
    }
    
    return false;
  });
}
```

**Теперь ищет в обе стороны:**
- Латиница → Кириллица (запрос конвертируется)
- Кириллица → Латиница (товар конвертируется)
- Латиница → Латиница (прямое совпадение)
- Кириллица → Кириллица (прямое совпадение)

## 🎨 Технические детали:

### Файл: `client/src/utils/productSearch.ts`

```typescript
/**
 * Универсальная функция поиска товаров
 */
export function searchProducts<T extends SearchableProduct>(
  products: T[],
  query: string
): T[] {
  if (!query || query.trim() === '') {
    return products;
  }
  
  const trimmedQuery = query.trim();
  
  return products.filter(product => {
    // Поиск по коду
    if (matchesQuery(product.code, trimmedQuery)) {
      return true;
    }
    
    // Поиск по названию
    if (matchesQuery(product.name, trimmedQuery)) {
      return true;
    }
    
    return false;
  });
}

/**
 * Проверяет совпадение с автоконвертацией
 */
function matchesQuery(text: string, query: string): boolean {
  const lowerText = text.toLowerCase();
  const lowerQuery = query.toLowerCase();
  
  // Прямое совпадение
  if (lowerText.includes(lowerQuery)) {
    return true;
  }
  
  // Конвертация латиницы в кириллицу
  const cyrillicQuery = uzLatToCyr(lowerQuery);
  if (cyrillicQuery !== lowerQuery && 
      lowerText.includes(cyrillicQuery.toLowerCase())) {
    return true;
  }
  
  return false;
}
```

## 📝 Правила конвертации:

### Двухбуквенные комбинации:
- `sh` → `ш` (shisha → шиша)
- `ch` → `ч` (choy → чой)
- `ng` → `нг` (rang → ранг)
- `yo` → `ё` (yo'l → ёл)
- `ya` → `я` (yaxshi → яхши)
- `yu` → `ю` (yuz → юз)
- `ye` → `е` (yel → ел)

### Специальные символы:
- `o'` → `ў` (o'yin → ўйин)
- `g'` → `ғ` (g'isht → ғишт)
- `q` → `қ` (qalam → қалам)
- `h` → `ҳ` (harf → ҳарф)

### Однобуквенные:
- `a` → `а`, `b` → `б`, `d` → `д`, и т.д.
