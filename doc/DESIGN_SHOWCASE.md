## 📐 Дизайн-система

```
🔴 PRIMARY (Red)

⚫ NEUTRAL (Gray Scale)
#ffffff - Белый фон
#fafafa - Вторичный фон
#e5e5e5 - Границы
#525252 - Вторичный текст
#171717 - Основной текст

🟢 SUCCESS
#10b981 - Успешные операции

🟡 WARNING
#f59e0b - Предупреждения

🔵 INFO
```

### Типографика

```
Шрифт: Inter (основной), JetBrains Mono (код)

Размеры:
12px - Мелкий текст, метки

Веса:
400 - Regular

```


### Скругления


## 🎯 Компоненты

### Кнопки

```tsx
// Primary - Основные действия
<Button variant="primary">Сохранить</Button>

// Secondary - Вторичные действия
<Button variant="secondary">Отмена</Button>

// Outline - Альтернативные действия
<Button variant="outline">Подробнее</Button>

// Ghost - Минимальные действия
<Button variant="ghost">Закрыть</Button>

// Danger - Опасные действия
<Button variant="danger">Удалить</Button>

// С иконкой
<Button icon={<Plus />} iconPosition="left">
  Добавить
</Button>

// Загрузка
<Button loading={true}>Сохранение...</Button>

// Размеры
<Button size="sm">Маленькая</Button>
<Button size="md">Средняя</Button>
<Button size="lg">Большая</Button>
<Button size="xl">Очень большая</Button>
```

### Инпуты

```tsx
// Обычный инпут
<Input
  label="Название"
  placeholder="Введите название"
  helperText="Минимум 3 символа"
/>

// С иконкой
<Input
  leftIcon={<User />}
  placeholder="Имя пользователя"
/>

// С ошибкой
<Input
  label="Email"
  error="Неверный формат email"
/>

// С успехом
<Input
  label="Пароль"
  success="Пароль надежный"
/>

// Пароль
<PasswordInput
  label="Пароль"
  placeholder="Введите пароль"
/>

// Поиск
<SearchInput
  value={search}
  onChange={(e) => setSearch(e.target.value)}
  onClear={() => setSearch('')}
  placeholder="Поиск..."
/>

// Textarea
<Textarea
  label="Описание"
  rows={4}
  resize="vertical"
/>
```

### Карточки

```tsx
// Базовая карточка
<Card variant="elevated" padding="md">
  <CardHeader 
    title="Заголовок"
    subtitle="Подзаголовок"
    icon={<Package />}
    action={<Button size="sm">Действие</Button>}
  />
  <CardContent>
    Содержимое карточки
  </CardContent>
  <CardFooter>
    <Button variant="outline">Отмена</Button>
    <Button variant="primary">Сохранить</Button>
  </CardFooter>
</Card>

// Карточка метрики
<StatCard
  label="Общая выручка"
  value="45.2M"
  change="+12.5%"
  changeType="positive"
  icon={<DollarSign />}
/>

// Карточка товара
<ProductCard
  image="/product.jpg"
  name="Товар А"
  code="1001"
  price={25000}
  stock={45}
  stockStatus="in-stock"
  onEdit={() => {}}
  onDelete={() => {}}
  onAddToCart={() => {}}
/>
```

### Модальные окна

```tsx
// Обычное модальное окно
<Modal
  isOpen={isOpen}
  onClose={() => setIsOpen(false)}
  title="Добавить товар"
  size="lg"
  footer={
    <>
      <Button variant="outline" onClick={() => setIsOpen(false)}>
        Отмена
      </Button>
      <Button variant="primary" onClick={handleSave}>
        Сохранить
      </Button>
    </>
  }
>
  <form>
    <Input label="Название" />
    <Input label="Цена" type="number" />
  </form>
</Modal>

// Подтверждение
<ConfirmModal
  isOpen={isOpen}
  onClose={() => setIsOpen(false)}
  onConfirm={handleDelete}
  title="Удалить товар?"
  message="Это действие нельзя отменить"
  variant="danger"
  confirmText="Удалить"
  cancelText="Отмена"
/>

// Drawer (боковая панель)
<Drawer
  isOpen={isOpen}
  onClose={() => setIsOpen(false)}
  title="Фильтры"
  position="right"
  size="md"
>
  <div className="space-y-4">
    <Input label="Поиск" />
    <Select label="Категория" />
  </div>
</Drawer>
```

```css

```

#### Focus (Фокус)
```css
focus:outline-none
focus:ring-4
focus:ring-red-500/20
focus:border-red-500
```

#### Disabled (Отключено)
```css
disabled:opacity-50
disabled:cursor-not-allowed
disabled:pointer-events-none
```

#### Loading (Загрузка)
