# Исправление бесконечного обновления страницы

## Проблемы и решения

### 1. Бесконечный цикл в контекстах
**Проблема:** Функции в контекстах не были обернуты в `useCallback`, что приводило к их пересозданию при каждом рендере и бесконечному циклу обновлений.

**Исправлено в:**
- `AuthContext.tsx` - обернул `login`, `logout` в `useCallback`
- `ThemeContext.tsx` - обернул `toggleTheme`, `setTheme` в `useCallback`
- `Kassa.tsx` - обернул `loadWorkerItems` в `useCallback`

### 2. 401 Unauthorized ошибки
**Проблема:** Контексты пытались загрузить данные до авторизации пользователя.

**Исправлено в:**
- `ProductsContext.tsx` - проверка токена перед загрузкой
- `CustomersContext.tsx` - проверка токена перед загрузкой
- `WarehousesContext.tsx` - проверка токена перед загрузкой

### 3. React Router предупреждения
**Проблема:** Отсутствовали future flags для React Router v7.

**Исправлено в:**
- `App.tsx` - добавлены `v7_startTransition` и `v7_relativeSplatPath`

### 4. Агрессивное обновление
**Проблема:** `StaffReceipts.tsx` обновлялся каждую секунду.

**Исправлено:**
- Увеличен интервал с 1 до 5 секунд

### 5. Избыточное логирование
**Проблема:** Слишком много логов в консоли.

**Исправлено:**
- Логи теперь выводятся только в dev режиме (`import.meta.env.DEV`)

## Результат
✅ Страница больше не обновляется бесконечно
✅ Нет 401 ошибок при загрузке
✅ Убраны предупреждения React Router
✅ Снижена нагрузка на сервер
✅ Чистая консоль в production
