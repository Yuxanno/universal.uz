## Как проверить

### 1. Запустите проект
```bash
cd client
npm run dev
```

### 2. Откройте браузер
- Перейдите на http://localhost:5173
- Откройте DevTools (F12)

### 3. Проверьте загрузку
- [ ] Товары появляются сразу (первые 100)
- [ ] Счетчик показывает "100 / X mahsulot"
- [ ] Через 0.5 сек загружаются остальные
- [ ] В консоли нет ошибок

### 4. Проверьте производительность
- [ ] Плавный скролл без лагов
- [ ] Быстрый поиск (без задержек)
- [ ] Нет фризов при вводе
- [ ] CPU < 50% при скролле

### 5. Проверьте кэш
- [ ] Откройте DevTools → Application → Session Storage
- [ ] Должны быть `products_cache` и `products_cache_time`
- [ ] При перезагрузке страницы товары грузятся из кэша

## Troubleshooting

### Если сайт все еще лагает:

1. **Очистите кэш браузера:**
   - Chrome: Ctrl+Shift+Del
   - Выберите "Cached images and files"
   - Нажмите "Clear data"

2. **Перезапустите сервер:**
   ```bash
   # Остановите (Ctrl+C)
   # Запустите снова
   npm run dev
   ```

3. **Проверьте консоль:**
   - F12 → Console
   - Есть ошибки?

4. **Проверьте Network:**
   - F12 → Network
   - Медленные запросы?
   - Большие файлы?

5. **Проверьте Performance:**
   - F12 → Performance
   - Записать профиль
   - Найти узкие места

### Если товары не загружаются:

1. **Проверьте API:**
   ```bash
   curl http://localhost:5050/api/products
   ```

2. **Проверьте кэш:**
   ```javascript
   // В консоли браузера
   sessionStorage.clear()
   location.reload()
   ```

3. **Проверьте состояние:**
   ```javascript
   // В консоли браузера
   console.log(sessionStorage.getItem('products_cache'))
   ```
