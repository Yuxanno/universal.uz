║     XPRINTER XP-365B DRIVER O'RNATISH (TEZKOR YO'L)         ║
╚══════════════════════════════════════════════════════════════╝

MUAMMO:
  Printer sozlamalarida "Type" qismida faqat "Фасонные этикетки" 
  bor, lekin "Continuous (Variable Length)" yo'q.

YECHIM:

┌──────────────────────────────────────────────────────────────┐
│ USUL 1: RASMIY SAYTDAN YUKLAB OLISH (ENG OSON)              │
└──────────────────────────────────────────────────────────────┘

1. Saytga kiring:
   http://www.xprinter.net/download

2. "XP-365B" ni toping va yuklab oling

3. Yuklab olingan .exe faylni ishga tushiring

4. "Next" -> "Install" -> "Finish"

5. Kompyuterni qayta ishga tushiring

6. Tekshirish:
   Control Panel -> Devices and Printers
   -> Xprinter XP-365B -> Right-click -> Printing Preferences
   -> "Type" qismida "Continuous (Variable Length)" bo'lishi kerak

┌──────────────────────────────────────────────────────────────┐
│ USUL 2: USB DAN O'RNATISH                                    │
└──────────────────────────────────────────────────────────────┘

1. USB diskdagi "XprinterDriver" papkasini oching

2. Control Panel -> Devices and Printers

3. "Add a printer" -> "The printer that I want isn't listed"

4. "Add a local printer" -> Next

5. "Use an existing port" -> USB001 -> Next

6. "Have Disk..." -> Browse

7. USB diskdagi INF faylni tanlang:
   XprinterDriver\INF\xprinter.inf

8. "Xprinter XP-365B" ni tanlang -> Next

9. O'rnatish tugaguncha kuting

10. Printer Properties -> Printing Preferences
    -> Type: "Continuous (Variable Length)"
    -> Width: 80mm
    -> Save

┌──────────────────────────────────────────────────────────────┐
│ USUL 3: SEAGULL DRIVER (PROFESSIONAL)                        │
└──────────────────────────────────────────────────────────────┘

1. Saytga kiring:
   https://www.seagullscientific.com/support/downloads/drivers/

2. "Seagull BarTender Driver" ni yuklab oling

3. O'rnating va printeringizni tanlang

4. "Continuous (Variable Length)" avtomatik paydo bo'ladi

┌──────────────────────────────────────────────────────────────┐
│ TEKSHIRISH                                                    │
└──────────────────────────────────────────────────────────────┘

PowerShell da quyidagi buyruqni ishga tushiring:

  Get-PrinterDriver | Where-Object {$_.Name -like '*XP*'}

Natija:
  Name              Manufacturer  
  ----              ------------  
  Xprinter XP-365B  Xprinter      

Agar "Manufacturer: Xprinter" ko'rinsa - MUVAFFAQIYATLI!

┌──────────────────────────────────────────────────────────────┐
│ YORDAM                                                        │
└──────────────────────────────────────────────────────────────┘

Agar muammo hal bo'lmasa:

1. Printerning USB kabelini sug'uring va qayta ulang

2. Windows Update qiling:
   Settings -> Update & Security -> Check for updates

3. Eski driverni to'liq o'chiring:
   Control Panel -> Devices and Printers
   -> Xprinter XP-365B -> Remove device

4. Kompyuterni qayta ishga tushiring

5. Qaytadan o'rnatib ko'ring
