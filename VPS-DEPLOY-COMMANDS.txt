=== VPS GA TIMEZONE FIX NI DEPLOY QILISH ===

MUAMMO: Bugungi savdo statistikasi VPS da 0 ko'rsatyapti, chunki server UTC vaqtida ishlayapti, 
lekin O'zbekiston UTC+5 da. Localhost to'g'ri ishlaydi chunki kompyuter vaqti to'g'ri.

YECHIM: stats.js faylida timezone offset qo'shildi (UTC+5)

=== 1-QADAM: Fayllarni VPS ga yuklash ===

Windows PowerShell da (loyihalar papkasida):

cd universal.uz

# Server faylini yuklash
scp server/src/routes/stats.js root@vmi3023927.contaboserver.net:/var/www/universalbozor/server/src/routes/

# Client build fayllarini yuklash
scp -r client/dist/* root@vmi3023927.contaboserver.net:/var/www/universalbozor/client/dist/


=== 2-QADAM: VPS ga ulanish va serverni restart qilish ===

ssh root@vmi3023927.contaboserver.net

# VPS ichida:
cd /var/www/universalbozor

# PM2 ni restart qilish
pm2 restart universalbozor-api

# Statusni tekshirish
pm2 status

# Loglarni ko'rish (agar kerak bo'lsa)
pm2 logs universalbozor-api --lines 50

# VPS dan chiqish
exit


=== 3-QADAM: Tekshirish ===

Brauzerda ochish: https://pos.universalbozor.uz

Dashboard da bugungi savdo statistikasini tekshiring.
Agar hali ham 0 ko'rsatsa, brauzer cache ni tozalang (Ctrl+Shift+R)


=== NIMA O'ZGARDI? ===

server/src/routes/stats.js faylida:

OLDIN:
  const today = new Date();
  today.setHours(0, 0, 0, 0);  // Server vaqti (UTC) ishlatilgan

HOZIR:
  const uzbekistanOffset = 5 * 60 * 60 * 1000; // 5 soat
  const uzbekistanNow = new Date(now.getTime() + uzbekistanOffset);
  const today = new Date(uzbekistanNow);
  today.setUTCHours(0, 0, 0, 0);
  const todayUTC = new Date(today.getTime() - uzbekistanOffset);
  // O'zbekiston vaqti (UTC+5) ishlatiladi
