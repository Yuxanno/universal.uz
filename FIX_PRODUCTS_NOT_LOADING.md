# Исправление: Товары не загружаются в других панелях

## Проблема
Товары не отображались в панелях кассира и POS (Kassa), пока пользователь не зайдет в админ панель.

## Причина
Компоненты использовали `ProductsContext`, который загружает товары только один раз при монтировании. Если при первой загрузке товаров не было (или кеш был пустой), они не загружались повторно при переходе на другие страницы.

### Последовательность проблемы:
1. Пользователь заходит на страницу кассира (первая страница после логина)
2. `ProductsContext` пытается загрузить товары, но их нет в кеше
3. Товары загружаются, но компонент уже отрендерился с пустым массивом
4. При переходе на другие страницы товары не обновляются
5. Только при заходе в админ панель (которая загружает товары напрямую через API) товары появляются

## Исправленные файлы

### 1. `client/src/pages/cashier/Products.tsx`

**Добавлено:**
```typescript
import { useState, useEffect, useMemo, useCallback, memo } from 'react';

// ...

const { displayedProducts, loading, refreshProducts } = useProducts();

// ...

// ИСПРАВЛЕНИЕ: Загружаем товары при монтировании, если их нет
useEffect(() => {
  if (displayedProducts.length === 0 && !loading) {
    refreshProducts();
  }
}, [displayedProducts.length, loading, refreshProducts]);
```

**Что делает:**
- Проверяет, есть ли товары при монтировании компонента
- Если товаров нет и не идет загрузка - вызывает `refreshProducts()`
- Это гарантирует, что товары загрузятся, даже если пользователь зашел на эту страницу первой

### 2. `client/src/pages/admin/Kassa.tsx`

**Добавлено:**
```typescript
const { displayedProducts, loading, refreshProducts } = useProducts();

// ...

// ИСПРАВЛЕНИЕ: Загружаем товары при монтировании, если их нет
useEffect(() => {
  if (displayedProducts.length === 0 && !loading) {
    refreshProducts();
  }
}, [displayedProducts.length, loading, refreshProducts]);
```

**Что делает:**
- Аналогично компоненту кассира
- Гарантирует загрузку товаров при открытии POS-системы

## Как это работает

### До исправления:
```
1. Пользователь → Страница кассира
2. ProductsContext монтируется → Проверяет кеш → Кеш пустой
3. Начинает загрузку товаров (async)
4. Компонент рендерится с displayedProducts = []
5. Загрузка завершается, но компонент не обновляется
6. Товары: 0 / 0 mahsulot ❌
```

### После исправления:
```
1. Пользователь → Страница кассира
2. ProductsContext монтируется → Проверяет кеш → Кеш пустой
3. Начинает загрузку товаров (async)
4. Компонент рендерится с displayedProducts = []
5. useEffect срабатывает → Видит, что товаров нет → Вызывает refreshProducts()
6. Товары загружаются и отображаются
7. Товары: 1094 / 1094 mahsulot ✅
```

## Дополнительные улучшения

### Кеширование
`ProductsContext` уже использует кеширование:
- Товары сохраняются в `sessionStorage`
- При повторном открытии страницы товары загружаются мгновенно из кеша
- Кеш действителен в течение времени, указанного в `PERFORMANCE_CONFIG.PRODUCTS_CACHE_TIME`

### Оптимизация
Благодаря ранее внедренным оптимизациям (см. `OPTIMIZATION_NOTES.md`):
- Загрузка товаров занимает 0.3-1 секунду
- Индексы в базе данных ускоряют запросы
- `.lean()` в Mongoose уменьшает размер данных

## Примечания

### Почему не использовать глобальную загрузку?
Можно было бы загружать товары один раз при входе в систему, но текущий подход лучше:
- Товары загружаются только когда нужны
- Кеширование работает эффективно
- Меньше нагрузка на сервер при входе

### Альтернативные решения
1. **React Query / SWR** - библиотеки для управления серверным состоянием
2. **Redux** - глобальное состояние приложения
3. **Загрузка при входе** - загружать товары сразу после логина

Текущее решение простое и эффективное для данного проекта.
